# Security Policy

## Scope

This repository primarily contains documentation, prompts, datasets and a static website. It must never contain production credentials or private operational data.

## Reporting a security or privacy concern

Do not publish credentials, guest data or exploitable details in a public issue. Report the concern privately through the professional contact channels on https://ahmedqualityops.com/.

Include the affected file, the type of risk, reproduction details where safe, and recommended containment steps.

## Supported version

The latest published release is supported. Older releases may remain available for reference but should not be used as the current governance standard.
