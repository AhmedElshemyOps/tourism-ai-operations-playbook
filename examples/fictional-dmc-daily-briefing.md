# Fictional Example — DMC Daily Briefing

> All names, bookings and details in this example are fictional.

A DMC is managing twelve movements across Abu Dhabi and Dubai. Two French-speaking groups require guides, one attraction slot remains pending, and a vehicle has not yet passed the readiness check.

Use Prompt 3.1 to create an exception-first briefing. The AI should identify missing confirmations, timing conflicts and assigned owners without inventing availability.

The duty manager must verify the briefing against the booking system, supplier confirmations, guide roster and fleet status before distribution.
