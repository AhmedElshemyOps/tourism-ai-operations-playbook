# Roadmap

## Version 1.0 — Foundation

- Ten complete tourism AI toolkits
- 100 individually documented prompts
- JSON and CSV prompt indexes
- Responsible-use and verification standards
- GitHub Pages edition
- Contribution and issue workflows
- Automated repository validation

## Version 1.1 — Practitioner Feedback

- Add field-tested improvement notes
- Expand accessible-tourism controls
- Improve regional and multilingual adaptation guidance
- Add prompt testing records and change rationale

## Version 1.2 — Training Edition

- Facilitator lesson plans
- Team exercises and role-play packs
- Prompt assessment rubric
- Department adoption checklist
- Manager approval register

## Version 2.0 — Operational Governance Edition

- Prompt registry and ownership model
- Risk classification framework
- Audit and incident dashboard templates
- Department access and version-control policy
- Evaluation methodology for output quality

Roadmap items are proposals, not commitments. Priorities will be informed by tourism-industry feedback and responsible-use needs.
